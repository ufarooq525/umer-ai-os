# Runtime Platform Playbook

> Narrative integrator for the AI OS kernel. Read after Charter, Domain Map, Domains/*, Lifecycles, Communication Model, Contracts, Ownership Boundaries, and Architecture Review.

Governed by `Runtime/RUNTIME_PLATFORM_CHARTER.md`.

## 1. One-Sentence Mandate

Runtime mechanically runs the organization without owning the organization’s decisions.

## 2. Placement

- **Layer:** Runtime (kernel)  
- **Sibling:** Execution (organizational orchestration semantics)  
- **Constrained by:** Core, Governance, Security Dept  
- **Serves:** Executive, Business, Departments, Agents (future), Human Principal  

## 3. How Work Crosses the Kernel

1. Human/system intent enters Session → Executive/Business as required.  
2. Execution admits a request/instance (organizational).  
3. Orchestration creates a Run; Context primed via Memory Access.  
4. Control Plane enforces gates; Trust authorizes; Economy admits.  
5. Departments receive stage work; Agent Runtime invokes specialists.  
6. Tools/models via Registry + Extension + Model Routing.  
7. Artifacts validate/seal; events flow on Message Fabric; Audit appends.  
8. Resilience checkpoints/retries; HITL for irreversible paths.  
9. Outcomes harvest to Intelligence; measurement to Analytics; value judgment to Business.  

## 4. Domain Map (17)

Kernel · Trust · Control Plane · Registry Fabric · Model Routing · Context · Memory Access · Orchestration · Artifact · Message Fabric · Resilience · Session/HITL · Economy · Observability · Audit · Extension · Agent Runtime  

## 5. Worked Example — Cross-Department Feature

Execution instance EXEC-042 scoped → Orchestration run → Design stage Agent under Trust → Artifact Design Handoff sealed → Gate wait → Eng Agent → Model Routing for codegen assist → Extension CI tool → QA verification evidence artifact → Control Plane release gate → HITL CEO go/no-go → Audit chain complete → Memory Access writeback lesson → Analytics instrumentation events (product plane) distinct from Runtime Observability.

## 6. What Not to Ask of Runtime

- “Should we build this?” → Business  
- “Who decides?” → Governance/Executive RACI  
- “Is UX right?” → Design/QA  
- “Is control adequate?” → Security  
- “What Capability exists?” → Enterprise Architecture  

## 7. Anti-Patterns (Kernel-Level)

Semantics theft from Execution; shadow Intelligence; fail-open Trust; chat approvals; model hardcoding; plugin egress freedom; product/platform observability mashup; Economy auto-waiving gates.

## 8. One-Sentence Summary

**Runtime is the decade-stable kernel: enforce trust and policy, orchestrate runs, route models, carry context and artifacts, recover safely, and audit everything consequential — while Execution means, Departments deliver, and Business decides value.**
