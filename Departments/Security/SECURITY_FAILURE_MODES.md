# Security Failure Modes

Governed by `Departments/Security/SECURITY_CHARTER.md`.

## Architectural Risks

| Mode | Consequence |
|---|---|
| Becoming a Pipeline Stage on every ticket | Artificial bottleneck; side channels spawn |
| Absorbing Governance Risk Framework | Policy and control ownership collapse together |
| Living only as Engineering/Security stub | No Constraining authority; security theater |
| QA owning control fail authority | Diluted accountability |
| Checkbox Threat Models | False assurance |

## Organizational Risks

Exception culture without risk acceptance logs; Security as permanent blocker brand; under-staffed Enabling dept ignored until breach.

## Long-Term Consequences

Uninsurable residual risk; identity sprawl; inability to attest controls; decade of bolted-on security after each incident.
