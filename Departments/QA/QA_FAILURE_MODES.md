# QA Failure Modes

Governed by `Departments/QA/QA_CHARTER.md`.

## Architectural Risks

| Mode | Consequence |
|---|---|
| Absorbed into Engineering | Self-certification; independence dies |
| Redefining Core Quality | Parallel quality universe |
| Owning Security testing authority | Control ownership blur with Security |
| Gate theater (checkboxes without evidence) | False release confidence |
| Blocking forever without criteria | QA as political veto, not verification |

## Organizational Risks

Schedule bullying into silent N/A; duplicate defect trackers vs Intelligence harvest; zombie QA; Phase-later Support bypassing QA into prod hotfixes without records.

## Long-Term Consequences

Normalized production failure; loss of trust in release RACI; Engineering slows from unpredictable reject chaos without learning loops.
