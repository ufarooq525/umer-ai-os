# QA Playbook

Governed by `Departments/DEPARTMENT_ARCHITECTURE_STANDARD.md` §12.

## 1. Mandate

QA independently verifies that releasable means fit for production — not merely built.

## 2. Placement

Domain QA · Capability Quality Assurance · Topology Pipeline Stage.

## 3. Enter / Leave

Enter on Engineering handoff acknowledgment. Leave via Validation Record into Execution/release RACI, or rejection returning ownership upstream.

## 4. Contexts

Strategy maps gates → Verification executes → Non-Functional assesses → Release Validation records → Quality Intelligence harvests themes.

## 5. Example

RC arrives → entry validation → Verification Record + NFR Report → Release Validation Record Pass → Execution gate evidence complete → lessons on recurrent defects harvested.

## 6. Business Traceability

Verify against Business success criteria on the Execution instance — do not invent alternate “QA success.”

## 7. Inheritance

Core Quality and Execution gates by link.

## 8. Escalation

Override pressure → CEO/Governance log; Security scope → Security; chronic rejects → CoS.

## 9. Anti-Patterns

Eng capture; gate theater; Security ownership grab; silent waivers.

## 10. Summary

**QA is independent assurance — Strategy, Verification, Non-Functional, Release Validation, Intelligence signals — so “built” never silently means “done.”**
