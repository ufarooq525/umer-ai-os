# Analytics Failure Modes

Governed by `Departments/Analytics/ANALYTICS_CHARTER.md`.

## Architectural Risks

| Mode | Consequence |
|---|---|
| Absorbing Portfolio Analytics | Business value loop collapses into dashboarding |
| Absorbing Observability | SLO owners vanish; page views mistaken for uptime |
| Shadow metrics per Department | No single dictionary; decision paralysis |
| Implementing all pipelines as Analytics-owned Eng | Dual delivery org |
| Experimentation without integrity | False product learning |

## Organizational Risks

Dashboard theater; PII sprawl; Analytics as report factory for every whim without Execution; zombie Analytics.

## Long-Term Consequences

Untrustworthy data culture; inability to close Business value loop; instrumentation rewrite every 2 years; privacy incidents.
