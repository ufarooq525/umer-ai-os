# Bounded Context: Engineering Systems

Governed by `Departments/Engineering/ENGINEERING_CHARTER.md`.

## Purpose

Own developer experience and delivery enablement tooling contracts — the merged home of “Developer Experience” and “Developer Productivity.” Productivity is measured; it is not a second context.

## Owns

Internal engineering tooling standards, CI foundation contracts (as Eng Systems concern), friction metrics inputs, golden ergonomics for Application Delivery.

## Does Not Own

Platform runtime (Platform); product analytics (Analytics); org-wide Knowledge systems (Intelligence); Agent specifications (Core — future Agents still Core-shaped).

## Interfaces

Enables Application Delivery and Release Engineering; Constrained by Security for tool supply chain; audited by CoS for documentation currency.

## Primary Artifacts

Engineering Standard (tooling/ergonomics subset), CI friction signals feeding Metrics.

## Anti-Patterns

Separating DevEx and Dev Productivity into rival empires; optimizing vanity activity metrics; tools that contradict Platform Standards.
