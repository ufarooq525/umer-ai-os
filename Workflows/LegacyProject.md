# Legacy Project Workflow

## Objective

Create a repeatable process for assessing, stabilizing, and modernizing an existing project.

## Stages

1. Audit current state
2. Identify risks and blockers
3. Prioritize technical debt
4. Prepare phased improvement plan
5. Implement with verification

## Inputs

- Existing codebase
- Known issues
- Constraints and deployment context

## Outputs

- Risk summary
- Modernization plan
- Execution order
- Validation checkpoints
