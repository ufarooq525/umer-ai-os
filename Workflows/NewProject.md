# New Project Workflow

## Objective

Define the standard path for starting a new project inside the Umer AI OS system.

## Stages

1. Intake and scope review
2. Repository and architecture setup
3. Team alignment and role assignment
4. Standards and checklists activation
5. Delivery plan and milestones

## Inputs

- Project brief
- Client or stakeholder goals
- Constraints and timeline

## Outputs

- Project folder structure
- Architecture summary
- Delivery milestones
- Quality checklist
