# Bug Fix Workflow

## Objective

Provide a repeatable triage and resolution path for bugs and regressions.

## Stages

1. Reproduce and isolate the issue
2. Capture expected vs actual behavior
3. Identify root cause
4. Implement a minimal fix
5. Verify and document the resolution

## Inputs

- Bug report
- Reproduction context
- Environment details

## Outputs

- Root cause summary
- Fix details
- Verification notes
- Prevention recommendations
