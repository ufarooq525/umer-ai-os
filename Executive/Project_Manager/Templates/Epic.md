# Epic Template

> A milestone-sized body of work, handed down from the CEO's delegation plan, decomposed by the Project Manager into [Tasks](Task.md) and scheduled across one or more [Sprints](Sprint.md).

```markdown
# Epic: <name>

## Metadata
- ID: <PROJECT-EPIC-##>
- Project: <link to Projects/<name>/brief.md>
- Owning Department(s): <e.g., Engineering, Design>
- Status: Planned | In Progress | Blocked | Done
- Target milestone (per CEO delegation plan): <name>

## Goal
The business/product outcome this epic exists to deliver — traceable to the CEO's brief, per Core/QUALITY_STANDARD.md's Business Value gate.

## Scope
### In scope
- <item>

### Out of scope (explicitly)
- <item — and why it's deferred, e.g. "custom dashboard builder — deferred post-MVP per CEO decision, see Projects/<name>/decisions.md">

## Definition of Done
- [ ] All child Tasks complete and accepted
- [ ] Applicable Core/QUALITY_STANDARD.md gates satisfied for this epic's deliverable type
- [ ] Handoff to next Core/WORKFLOW_STANDARD.md stage complete, per handoff rules

## Dependencies
- Depends on: <epic/external ID, or "none">
- Blocks: <epic ID, or "none">

## Child Tasks
| Task ID | Title | Owner | Status |
|---|---|---|---|
| | | | |

## Risks
| Risk | Likelihood | Impact | Mitigation | Owner |
|---|---|---|---|---|
| | | | | |
```
