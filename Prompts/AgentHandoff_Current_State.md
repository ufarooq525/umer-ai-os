## Operating Instructions for Future Agents

1. Do not recreate the baseline repository structure unless the user explicitly requests it.
2. Preserve the current architecture and naming convention.
3. Treat this project as a long-term internal system for reusable AI work.
4. Add real content, standards, policies, and workflow material rather than creating more empty folders.
5. Keep the repository organized, consistent, and reusable across future AI tools.
6. Prefer quality, structure, and long-term maintainability over quick markdown generation.

## Primary Objective

Build this into a durable operating system that can scale over time with:
- clear department ownership,
- reusable knowledge assets,
- standards that guide output,
- templates and checklists for repeatable quality,
- and memory that helps future agents act consistently.

## Important Reminder

This is not a prompt library. It is a system of reusable operating knowledge for future AI-assisted execution.
